# Changelog

## 1.0.0
- Initial release
- Split-flap flip animation with a two-phase leaf rotation
- Dark, light, and follow-colour-scheme themes
- Seconds as a sweeping bar, a third flip card, or hidden
- 12/24 hour, optional date line
- Panel support: sizes to panel thickness in horizontal panels, stacks the
  cards in vertical ones
- Scales continuously with the widget
- Configurable font family
- Tooltip, and accessibility metadata for screen readers
